# Minha Orquestradora — instalador

Aplicativo para Windows (com o Claude Code no Linux do Windows, WSL) que monta a SUA orquestradora de agentes:
ele lê o que você já tem (memória do Claude, rotinas, skills), propõe agentes, confere cada um antes de criar,
liga as suas contas e instala a mesa de aprovação (Vigia), onde tudo que é decisão chega numa tela só.

Baixar: https://github.com/VSATORES/minha-orquestradora-dist/releases/latest/download/minha-orquestradora-setup.exe

O app se atualiza sozinho por este repositório. Os sistemas de cada empresa entram por um arquivo de perfil
(.json) que fica fora daqui.
